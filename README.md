# L-2.1web
 
## Для запуска необходимы

*   Docker и Docker Compose
*   Node.js
*   yarn


## Инструкция для запуска

1.  **Клонирование репозитория:**

    ```bash
    git clone https://github.com/salimjon10/L-2.1web
    cd L-2.1web
    ```

2.  **Настройка переменных окружения:**

    При необходимости настройте переменные окружения в файле `.env` для каждого сервиса.

3.  **Сборка и запуск сервиса:**

    В корневой директории проекта выполните следующую команду:

    ```bash
    docker-compose up --build
    ```
